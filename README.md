## 💡 Quick Reference: Essential Cmdlets

| Cmdlet | Description |
|---|---|
| `Get-Help <cmdlet> -Online` | View detailed help and examples |
| `Get-Command *<pattern>*` | Search for commands, cmdlets, functions |
| `Get-Member` | Discover object properties and methods |
| `Get-ChildItem` | List items in directory (`ls` / `dir`) |
| `Set-Location` | Change working directory (`cd`) |
| `Write-Host "..."` | Output text directly to the console |
